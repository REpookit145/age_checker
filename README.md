# Age Checker

A small Python terminal script that asks for your age and tells you whether you're a **Kiddo**, **Underage**, or an **Adult** — with a colorful rainbow ASCII-art title.

## What it does

- Prints a rainbow-colored "AGE CHECK" banner using `pyfiglet`
- Asks you to enter your age
- Tells you:
  - **Kiddo** — under 10
  - **Underage** — 10 to 17
  - **Adult** — 18 and older

## Python Setup (if you don't have Python yet)

1. Go to [python.org/downloads](https://www.python.org/downloads/) and download the latest version
2. Run the installer
3. **Important:** On the first install screen, check the box that says **"Add python.exe to PATH"** before clicking Install — this makes sure the `python` command works in your terminal
4. To check it worked, open a terminal (PowerShell/cmd) and type: python --version if it show current Version you Ready To go


### Option 1: Just double-click (easiest, Windows)

1. Download both `Age_Checker.py` and `Start.bat` into the same folder
2. Double-click `Start.bat`
3. Done — a terminal window opens, shows the banner, and asks for your age

### Option 2: Run it from a terminal

1. Download `Age_Checker.py`
2. Open a terminal and navigate to the folder where you saved it, for example: cd Downloads
3. Run the script: python Age_Checker.py
