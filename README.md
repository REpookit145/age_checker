# Age Checker

A small Python terminal script that asks for your age and tells you whether you're a **Kiddo**, **Underage**, or an **Adult** — with a colorful rainbow ASCII-art title.

## What it does

- Prints a rainbow-colored "AGE CHECK" banner using `pyfiglet`
- Asks you to enter your age
- Tells you:
  - **Kiddo** — under 10
  - **Underage** — 10 to 17
  - **Adult** — 18 and older

## Requirements

- [Python](https://www.python.org/downloads/) installed on your computer
- The `pyfiglet` library — the script installs it automatically the first time you run it, no manual setup needed

## How to run it

### Option 1: Just double-click (easiest, Windows)

1. Download both `Age_Checker.py` and `Start.bat` into the same folder
2. Double-click `Start.bat`
3. Done — a terminal window opens, shows the banner, and asks for your age
